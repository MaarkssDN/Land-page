# Birth Hub 360° — Hero Lab

Laboratório isolado de estudos visuais do Hero. Não altera a landing oficial nem a plataforma.

Servir: `python -m http.server 5400` dentro desta pasta, depois abrir http://localhost:5400/

| Item | Caminho | Tema nativo |
|---|---|---|
| Índice / central do laboratório | `index.html` | dark |
| Candidato atual · N1 Final Candidate | `mission-06/n1-final/index.html` | dark/light |
| Homologação Missão 06 | `mission-06/compare.html` | dark |
| Light Mode Alt A / Alt B | `mission-06/light-alt-a/`, `mission-06/light-alt-b/` | light |
| Conceitos originais | `concept-a/`, `concept-b/`, `concept-c/` | dark/light/light |
| B V2 e estudos neon | `concept-b2/`, `concept-n1/`, `concept-n2/`, `concept-n3/` | dark/light |
| Refinamentos Missão 05 | `mission-05/n1/`, `mission-05/n2/`, `mission-05/n3/` | dark/light |

Parâmetros de URL: `?theme=dark|light`, `?bare=1` (esconde a barra do laboratório), `?static=1` (estado final sem animação; usado nas capturas), `?motion=reduce` no candidato N1.

Todas as interfaces do produto são **simulações ilustrativas**; os CTAs são demonstrativos e não executam ação real.
